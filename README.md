# Vadex — сайт-визитка

Чёрно-белая визитка веб-разработчика: летающие частицы на фоне (реагируют на курсор), печатающийся заголовок, семнадцать работ с ссылками на живые сайты (у части — и на исходный код).

## Что внутри

- `index.html`, `style.css`, `app.js` — без сборки и зависимостей, только шрифт JetBrains Mono с Google Fonts.
- Список работ — массив `W` в начале `app.js`: название, описание, стек, ссылка на сайт и, если есть, имя репозитория `g`.
- Кнопка «частицы» внизу выключает анимацию; при настройке системы «уменьшить движение» она отключена сама.

## Публикация

GitHub Pages: Settings → Pages → ветка `main`, папка `/ (root)`.
